# Example scenarios

Eight synthetic scenarios, each with a source export (`source.csv`), a CRM export (`destination.csv`) and a run configuration (`run.toml`). They double as end-to-end test fixtures.

All data is fictional: emails use the reserved `example.com`, `example.org` and `example.net` domains, and phone numbers use the `555-0100` to `555-0199` range reserved for fictional use. Files are generated by [`scripts/generate_examples.py`](../scripts/generate_examples.py) from [`base-config.toml`](base-config.toml); do not edit them by hand. The test suite fails if they drift from the generator.

| Scenario | What it shows | Result |
|---|---|---|
| [`a-lead-id-preserved`](scenarios/a-lead-id-preserved) | The CRM stores each lead's original ID | 27 verified, 3 missing, 1 pending; 1 late, 1 missing campaign ID, 1 invalid phone |
| [`b-lead-id-not-preserved`](scenarios/b-lead-id-not-preserved) | The same leads as A, through an integration that keeps no lead ID | 0 verified; 25 identity matches, 2 ambiguous, 3 missing, 1 pending |
| [`c-same-person-two-leads`](scenarios/c-same-person-two-leads) | One contact for two leads: with one ID stored, and with both | 7 verified, 2 merged, 1 ambiguous (record claimed by another lead) |
| [`d-timezone-uncertain`](scenarios/d-timezone-uncertain) | CRM local time declared as UTC | Timezone finding; 19 verified without latency, 2 undecidable |
| [`e-verified-duplicate`](scenarios/e-verified-duplicate) | Two leads replayed into new records | 13 verified, 2 duplicated |
| [`f-preexisting-contact`](scenarios/f-preexisting-contact) | People who existed in the CRM before their lead | 12 identity matches, 3 ambiguous (preexisting) |
| [`g-excluded-lead-arrived`](scenarios/g-excluded-lead-arrived) | Excluded test leads, one of which reached the CRM | 12 verified, 2 excluded (1 noted), 1 orphan |
| [`h-campaign-id-never-sent`](scenarios/h-campaign-id-never-sent) | The campaign ID is never transmitted | 1 pipeline finding instead of 25 errors; 1 wrong campaign name |

Build all reports into `reports/<scenario>/` (`report.html`, `exceptions.csv`, `summary.json`):

```bash
uv run python scripts/build_reports.py
```

Run a single scenario from Python:

```python
from pathlib import Path
from lead_integrity.config import execute, load_run

result = execute(load_run(Path("examples/scenarios/a-lead-id-preserved/run.toml")))
print(result.counts())
```
